This project was a product of a Bioinformatics class. At the time of this class, there were multiple seismic events recorded throughout the Philippines, prompting me to explore earthquake magnitude patterns by using publicly available data from the Philippine Institute of Volcanology and Seismology (PHIVOLCS). A linear regression model was developed in RStudio to examine whether spatial and temporal variables including latitude, longitude, earthquake depth, year, and month, could explain variations in earthquake magnitude.

The dataset was cleaned, encoded, and explored through exploratory data analysis before any model development and evaluation. The final model achieved an R² of approximately 3.6%, indicating that the selected variables explained a limited proportion of the variation in earthquake magnitude. The model captured general trends among smaller-magnitude events, but it frequently underestimated higher-magnitude earthquakes.

The results demonstrate that spatial and temporal earthquake characteristics can provide insights into seismic patterns, but additional geophysical and environmental variables are needed to improve predictive performance. Overall, this project demonstrates the application of R-based statistical modeling and data analysis to Philippine seismic data, providing a foundation for earthquake trend analysis and potential applications in seismic monitoring and disaster preparedness.
